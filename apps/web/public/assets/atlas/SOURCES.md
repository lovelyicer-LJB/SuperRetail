# Globe reference assets

Reference: https://www.huaweicloud.com/ (retrieved 2026-10-01).

- earth-map.png: https://res-static.hc-cdn.cn/cloudbu-site/china/zh-cn/3d-map_3.png
- earth-fallback.png: https://portal.hc-cdn.com/cpage-pep-home-page/2.0.30/components/global-site-3d/images/earth_bg.png
- earth-locations.json uses the reference page's earth-source coordinates, including its texture longitude offset. These are reference locations, not SuperRetail operating locations.

Assets are served locally. The renderer is independently implemented with Three.js; no Huawei scripts, analytics or runtime requests are included. Source assets remain subject to their original rights.
