# 图表「LOD 地图」画板内操作逻辑 v0.1

- 日期：2026-10-13
- 范围：版图页（Atlas）图表「LOD 地图」在画板中的全部操作逻辑；以画板框架既有约定为基线（`apps/web/src/modules/atlas/board/engine.ts` 头注【框架约定 · Del 删除】【框架约定 · 画板坐标 + 屏幕钉】）
- 代码：`apps/web/src/modules/atlas/map/`（AtlasMap / WorldMap / ChinaMap / ProvinceMap / AmapView），放置层 `AtlasPage.tsx`

## 0. 基线：画板通用手势（放置物适用）

| 手势 | 画板背景 | 引擎卡片 | LOD 地图放置卡 |
| --- | --- | --- | --- |
| 左键拖 | 框选（Ctrl/Cmd 追加） | 拖动卡片 | 内容区归地图本体；顶部名称把手拖卡片 |
| 中键拖 | 平移画布（任意位置） | 同左（冒泡到画布平移） | 卡内无行为（不在引擎根子树内） |
| 滚轮 | 无行为 | 无行为 | 归地图本体（仅 LOD3 缩放） |
| Ctrl/Cmd + 滚轮 | 缩放画布（光标锚定，90–120% 吸附 100%） | 同左 | 卡内无行为（事件不经引擎根，天然隔离） |
| 双击 | 空白处新建 Note | — | 卡内不建 Note；高德引擎双击为地图放大 |
| 右键 | 画板菜单（拆分/收起/删除等） | 卡片菜单（屏幕钉等） | 「屏幕钉」菜单（钉住/取消） |
| Del / Backspace | 删除选中卡片 | 同左 | 删除选中的放置卡（两层选择互斥） |
| 左键点按 | 清空选区 | 选中 | 选中放置卡（内容区点按同样选中） |

隔离原理：放置卡挂在画板区容器内、与画板引擎根同级（非其后代），指针/滚轮事件不冒泡到引擎根；画板手势只在画板背景上成立，两者互不干扰。唯一共享的是选择态与 Del 删除（页面层与引擎层选择互斥，按一次 Del 只删一边）。

## 1. 三种存在形态

| 形态 | 入口 | 交互能力 |
| --- | --- | --- |
| 缩略图 | 顶部「图表」按钮 → 浮窗 → Charts 组 | 不可交互（pointer-events 关闭）；点击 = 大图预览；拖拽 = 放置到画板 |
| 大图预览 | 点击缩略图（或 `?preview=scene.lod-map` 深链） | 完整可交互（interactive 标记：面板放行指针/滚轮）；Esc / 点遮罩 / ✕ 关闭 |
| 画板放置实例 | 从浮窗拖缩略图到画板 | 完整可交互；初始等比缩小到可视区 60% 以内，随画布平移/缩放（世界坐标），可屏幕钉 |

放置卡结构：内容区（地图本体，放行指针/滚轮）+ 顶部名称把手（拖卡片）+ 右上角 ✕（移除）+ 右键屏幕钉。点按内容区即选中卡片（天蓝边框），此时 Del 删除整卡——与画板「按下即选中」约定一致。

## 2. 三层 LOD 逐层操作逻辑

面包屑常驻顶部：世界地图 / 中国 / {省名}，上级可点击回跳；层级切换带 0.42s 过渡动画。

### LOD1 · 世界地图（3D 地球 → 平面展开）

| 操作 | 效果 |
| --- | --- |
| 进场 | 900ms 球面停留（对准中国）→ 1600ms 展开为平面 |
| 球面阶段左键拖 | 旋转地球（展开后锁定） |
| 点击中国区域 | 进入 LOD2（射线 → 经纬度 → 中国包围盒判定；球面/平面两态均可） |
| 点击「中国 · 进入」热区 | 进入 LOD2（仅平面态显示） |
| 「↻ 展开」按钮 | 重播展开动画 |
| 滚轮 | 无行为 |

### LOD2 · 国家地图（高德真底图 / SVG 兜底）

| 操作 | 高德引擎 | SVG 兜底引擎 |
| --- | --- | --- |
| 悬停省 | 覆盖层提亮 | 高亮 + 名称提示 |

| 操作 | 高德引擎 | SVG 兜底引擎 |

## 3. 2.5D 俯视（LOD3 最终层）

俯视是 LOD3 的姿态层（不是独立 LOD）：地块倾斜 52°–55°、挤出投影/地面光晕，用于全局鸟瞰。

### 进入（两条路径，等价）

1. **显式入口**：右侧缩放控件组「2.5D」按钮——任意缩放级别直接进俯视（俯视态按钮金色高亮）。
2. **手势路径**：滚轮缩到最小——穿越阈值时自动进入（SVG：k ≤ 1.12；高德：zoom ≤ 6.2）。刚进入 LOD3 时即最小缩放，默认就是俯视态。

### 退出（两条路径，等价）

1. 再点「2.5D」按钮（按钮高亮态）。
2. 滚轮放大穿越阈值（SVG：k ≥ 1.32 回差退出；高德：zoom > 6.2 穿越退出）。

### 手动 / 自动仲裁（两引擎同一语义）

- 俯视状态只在「穿越缩放阈值」时被自动改写；阈值范围内缩放不会覆盖手动按钮设定的姿态。
  - 例：俯视态下轻微放大（未过阈值）仍保持俯视；继续放大穿越阈值才回平面。
  - 例：平面态（zoom > 6.2）点按钮进俯视后，在该范围内缩放保持俯视；缩回最小穿越阈值时维持俯视（自动与手动同向）。
- SVG 侧由回差状态机天然实现（TILT_ON 1.12 / TILT_OFF 1.32）；高德侧由「上次缩放侧阈值态」记录实现（仅穿越时 setPitch）。
- SVG 俯视锁 k=1（平移归零）：俯视即复位鸟瞰全景；高德俯视不改 zoom，可继续拖动平移。
- 角标文案随姿态切换：平面态「滚轮缩放至市一级 · 缩到最小或点 2.5D 进入俯视」；俯视态「2.5D 俯视 · 滚轮放大或再点 2.5D 返回平面」。

## 4. GI 点位层（LOD2/LOD3 共用）

- 数据：`public/assets/atlas/gi-points.json`（1057 点：GI 821 / AGI 236；`tools/build-gi-points.mjs` 可重建）。
- 聚合随缩放散开/合拢；✦ 在册资产（12 款）不参与聚合，独立金标。
- 高德引擎：✦ 点击弹资产小卡，点地图空白关闭；SVG 引擎：悬停显示名称。
- 图例常驻右下角。

## 5. 引擎差异与降级

| | 高德真底图（已配 Key） | SVG 内置边界（兜底） |
| --- | --- | --- |
| 触发 | `amap.ts` 常量或 localStorage `sr.amap.key` | 无 Key / 高德脚本加载失败自动降级 |
| LOD2 | 真底图 + 省界覆盖层 | 内置 GeoJSON 省界 |
| LOD3 缩放 | zoom 4.5–12 | k 1–9（viewBox 变换） |
| 2.5D | setPitch(55)（viewMode 3D） | CSS perspective rotateX(52deg) + 挤出投影 |
| 角标 | 含 2.5D 提示 | 含 2.5D 提示 + 「内置边界模式」 |

两引擎 adcode 体系一致，进省行为一致；操作逻辑（含 2.5D 入口）逐条对齐。
